# Руководство администратора Helpes

Войдите на `/login/`. Меню: **Заявки**, **Панель**, **Пользователи**, **Справочники**.

## Первый запуск: что настроить
1. **Этажи** (Справочники → Этажи → «Добавить этаж»). Названия свободные: «1 этаж», «Цокольный», «5 этаж».
   Здания необязательны: если они не нужны, оставьте поле «Здание» пустым.
2. **Кабинеты** (Справочники → Кабинеты): выберите этаж и назовите кабинет.
   Список кабинетов можно заполнять постепенно — пока нужного кабинета нет, сотрудник выберет
   «Моего кабинета нет в списке» и опишет место текстом.
3. **Категории** (Справочники → Категории): стартовый набор уже создан. Добавляйте свои, меняйте порядок
   числом в поле «Порядок» (меньше — выше в списке).
4. **Техники** (Пользователи → «Новый пользователь»): имя, логин, пароль (не короче 8 символов), роль «Техник».
   Администратору можно дать обе роли — тогда он сможет и брать заявки в работу.

Новый этаж/кабинет/категория появляются в форме сотрудника сразу, без перезапуска и правок кода.

## Скрытие вместо удаления
Записи справочников не удаляются: кнопка **«Скрыть»** убирает их из формы, но старые заявки сохраняют
своё местоположение и категории. Скрытый этаж скрывает все свои кабинеты; скрытое здание — свои этажи.
Переименование кабинета не меняет текст местоположения в уже созданных заявках.

## Работа с заявками
- **Заявки → вкладки**: «Свободные», «Мои», «Все открытые», «Давно без обновлений» (дольше `HELPES_STALE_HOURS`
  часов, по умолчанию 48), «Выполненные». Есть поиск и фильтры. Страница сама обновляется раз в минуту.
- Откройте заявку → блок **«Назначение»**: выберите техника → «Назначить» / «Переназначить». Работает для любой
  незавершённой заявки независимо от текущего исполнителя.
- **«Вернуть в очередь»** снимает исполнителя и ставит статус «Новая».
- **Повторное открытие** выполненной заявки: предыдущее завершение (дата и результат) остаётся в истории.
- Вся история (создание, взятие, назначения, смены статуса, повторные открытия) видна в карточке заявки.

## Недоступен техник (болезнь, увольнение)
Пользователи → «Отключить». Система покажет его незавершённые заявки и потребует выбрать:
передать другому активному технику или вернуть в общую очередь. Затем учётная запись отключается
(войти нельзя), история выполненных работ сохраняется. Включить обратно — кнопка «Включить».
Защита от ошибок: нельзя отключить себя и последнего активного администратора.

## Роли
- **Техник**: видит очередь, берёт свободные заявки, меняет статус и пишет результат по своим заявкам,
  возвращает свои заявки в очередь, комментирует. Не может: создавать пользователей, менять справочники,
  назначать роли, назначать заявки другим.
- **Администратор**: всё остальное. Суперпользователь Django (`createsuperuser`) всегда администратор.

## Забыт пароль
Пользователи → «Изменить» → введите новый пароль. Если забыт пароль единственного администратора:
`python manage.py changepassword <логин>` на сервере.
